# Monster Throne v0.7 — Этап 1: Герой и развитие

Первая версия из утверждённой дорожной карты после ручного теста v0.6.1.

## Цель

Не расширять карту и экосистему. Сделать развитие героя настоящей системой, которую можно почувствовать руками.

## Характеристики

Герой имеет четыре постоянные характеристики:

- **Сила** — базовый урон и переносимый вес;
- **Выносливость** — HP, запас сил и физическая защита;
- **Ловкость** — скорость, рывок и часть атаки;
- **Интеллект** — качество анализа существ и исследований.

Пища, добыча и значимая практика сначала создают **скрытый потенциал характеристик**. При нормальном питании тело постепенно усваивает этот потенциал и превращает его в выраженные характеристики.

Уровень сам не создаёт характеристики. Характеристики определяют поддерживаемый потолок, а уровень созревает к нему с базовым темпом `1 уровень / 60 секунд`.

Победа над более сильной целью даёт временный импульс скорости созревания: примерно `+1%` за уровень разницы, пока герой не приблизится к уровню побеждённого существа.

## Навыки

Навыки теперь влияют на игру:

- Копьё — урон и немного темп атаки;
- Выживание — польза еды, лечения и перевязок;
- Ловушки — урон и удержание ловушек;
- Разделка — усвоение постоянного потенциала добычи;
- Ремесло — качество простых изделий (в текущем срезе вместе с ловушками);
- Исследование — качество анализа и подсказок после неудачных опытов.

`mastery` не деградирует. `readiness` показывает текущую готовность навыка и может остывать без практики.

## Сохранения

Отдельный формат v0.7:

- автосохранение;
- быстрое сохранение;
- 3 ручных слота;
- загрузка из любого слота;
- экспорт сохранения в JSON;
- импорт JSON в Слот 1.

Сохранения v0.6.x специально не смешиваются с v0.7, чтобы мясной эксплойт и старые коэффициенты не загрязнили тест новой прогрессии.

## Запуск

Из корня ветки:

```bat
START_GAME_V07.bat
```

или:

```bash
py -m http.server 8080
```

Открыть `http://localhost:8080/hero07/`.

## Проверки

- `node --check` проходит;
- 11/11 runtime-тестов через Node VM: стартовые характеристики, производные параметры, потенциал, навыки, импульс сильной победы, перегрузка, сохранение/загрузка, созревание уровня;
- 100 000 случайных профилей характеристик: монотонность потолка не нарушена;
- перекос в одну характеристику даёт заметно меньший потолок, чем сбалансированное тело с тем же общим бюджетом.

Числовой баланс всё ещё `[EXPERIMENT]` до ручного теста автора.
