# Monster Throne Hero v0.8 Stage 2A

Поверх неизменённых формул героя v0.7.2 добавлен детерминированный секторный мир: круглый остров диаметром 16 км, подгрузка 3×3 активных и 5×5 подготовленных секторов, сохранение изменений и туман исследования на мини-карте.

Исправляющий проход по Этапу 1: понятное развитие, предметный крафт и честный расчёт удара.

## Запуск

Из корня репозитория:

```bat
START_GAME_V072.bat
```

Или вручную:

```bash
py -m http.server 8080
```

Открыть `http://localhost:8080/hero072/`.

## Что проверять вручную

1. Открыть `K → Навыки` и увидеть диапазон урона, вклад оружия, Силы, Ловкости, мастерства, готовности и защиты цели.
2. Ударить выбранного врага и раскрыть последнюю строку боевого журнала: она использует ту же формулу.
3. В `C → Рецепты` изготовить верёвку, костяной наконечник, костяной нож и улучшенное копьё.
4. Проверить массовый крафт и кнопку `Макс`.
5. Перейти в `C → Свободный эксперимент`: результат не обещается заранее, материалы могут быть испорчены, наблюдение попадает в Книгу мира.
6. Сохранить игру, перезагрузить страницу и загрузить слот. Улучшенное оружие, навыки и характеристики должны сохраниться.

## Автоматическая проверка

```bash
node tests/hero-v072.test.js
node tests/sector-world.test.js
```

Локально пройдено `9/9` проверок формул боя, рецептов, массового крафта и миграции сейва. `rules.js` и полный читаемый `game.js` проходят `node --check`.

Полноценный автоматический браузерный smoke в рабочем окружении не выполнен: Chromium аварийно завершал GPU-процесс до загрузки страницы. Поэтому фактический запуск в Chrome остаётся обязательной ручной проверкой.
