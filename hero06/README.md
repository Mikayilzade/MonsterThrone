# Monster Throne v0.6 — Исследователь и выживальщик

Ручная игровая ветка после первого теста Hero Demo v0.5.

## Основной цикл

`найти → осмотреть → подобрать → положить в сумку → использовать/обработать → записать результат → скрафтить → применить → узнать больше`

## [USER DIRECTION] Знание мира

Истинные свойства растений, материалов и существ существуют с первой секунды мира. Они не открываются потому, что герой достиг искусственного уровня «Алхимия 50». Книга показывает только то, что герой реально проверил или достаточно хорошо наблюдал. Редкое применение простого стартового растения может оставаться неизвестным десятки или сотни часов, пока игрок сам не попробует подходящую комбинацию.

## Добавлено

- отдельный инвентарь: `E` подбирает, `F` использует объект прямо в мире;
- 8 слотов быстрого доступа, предметы назначаются из сумки;
- выбор противника кликом, HP, категория угрозы, накопление реальных знаний о виде;
- всплывающий урон и журнал последних ударов;
- базовый крафт и готовка у лагеря;
- свободные эксперименты без искусственных уровневых блокировок;
- скрытые комбинации материалов, работающие с первой секунды мира;
- Книга мира: флора, фауна, подтверждённые открытия;
- свойства растений раскрываются только после соответствующего опыта;
- экран `Продолжить / Новая игра`;
- автосохранение раз в 12 секунд, при паузе и уходе со вкладки;
- большой круглый остров с морской границей;
- ПК и базовое сенсорное управление.

## Управление

- `WASD` / стрелки — движение
- мышь / `Space` — удар; первый клик по существу выбирает его, повторный атакует
- `Shift` — рывок
- `E` — подобрать / разделать
- `F` — использовать / съесть прямо в мире
- `I` — инвентарь
- `C` — крафт и эксперименты
- `J` — Книга мира
- `P` / `Esc` — пауза
- `1–8` — использовать быстрый слот

## Запуск

Из корня скачанной папки:

```bash
py -m http.server 8080
```

Открыть:

```text
http://localhost:8080/hero06/
```
